01 · DURABLE

A crash resumes, it doesn't restart.

Each step commits in the same transaction as the work it schedules. Replay never calls a model or tool twice.

clank run events publish-weekly-8d1 -n blog
#14 step.completed  draft
#15 node.lost       eu-1
#16 step.resumed    draft ← #14
02 · BROKERED

Agents never hold a key.

They name a claim. The gateway on their node holds the real credential, reserves budget, and records who spent what.

kind: ModelClaim
spec:
  providerConnection: anthropic
  model: claude-sonnet
  budget: blog/monthly
03 · GATED

Some actions wait for a person.

Publishing, paying, deleting: mark the tool, and the run parks in an inbox until someone says yes. The yes is in the audit log.

clank approvals -n blog
publish.post  writer  2m ago  waiting
clank approve a-91c2 --reason "LGTM"

One binary on Postgres.
A small daemon per machine.

Nodes dial the control plane, never the reverse, so they can sit behind NAT. Postgres is the source of truth and the message bus: dispatch is SKIP LOCKED, wake-ups are NOTIFY, leadership is a lease row. Every lease is fenced by an epoch, so a node that lost an instance can't commit stale results.
