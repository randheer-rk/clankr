# Landing page (site/src/App.tsx)

Scope: the public landing page. Mode: Persuade. Audience: hands-on engineers (platform/infra and agent developers). Action: start the quick start. Proof: the real run log, CLI snippets, three films. Constraints: Lockbot mark and its eye animation unchanged; palette and fonts from palletism Pixel Arcade + Pop Grain (owner-pinned).

## Direction contract

THESIS: The page is an arcade cabinet in attract mode: a real run plays itself and stops at the gate for the visitor. Refuses the dark dev-tool page of headline, terminal panel and feature grid.

OWN-WORLD: The screen is Pixel Arcade: midnight #1A1C2C ground, #242740 panels, screen white #FFF1E8, arcade red #FF004D for danger and the primary action, coin blue #29ADFF for recovery. The cabinet's print is Pop Grain: a sticker-yellow #FFD23F marquee and side-art band, a cream #F5F1E6 instruction card, tape black #221E22 ink, hot pink #FF4365 stickers. Jersey 15 for everything on screen, Bagel Fat One for print, Rubik for reading. Square pixels, no radii on screen, stepped motion.

STORY: The visitor sees a run survive a dead node, approves the gated step themselves, believes the log, and starts the quick start.

FIRST VIEWPORT: Yellow marquee nav (Lockbot, Clankr, links). Below it one full-bleed midnight screen: HUD row (run id, event count, nodes as lives); headline "Agents that work shifts, not demos." in Jersey 15 at left, large; lede and the red primary button "Build it in an afternoon" under it; the playfield along the bottom, full width: two node platforms, the agent sprite, Lockbot as the gate at the right, the last event as a caption.

Signature interaction: the run parks at Lockbot's gate with a running wait clock until the visitor presses Approve; then the gate opens and the audit line seals. Motion grammar: steps() timing, blink, sprite hops; nothing eases softly.

FORM: arcade attract screen and cabinet print; position 1 of 7 on the ordered list (chosen by the owner as the pick card over the dealt candidate 5); seed:c99a476b4c0e8b3f.
