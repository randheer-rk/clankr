step one · contain

0routes out, by default

Every agent gets a box.

A rootless container, a gVisor sandbox, or a Firecracker microVM. Read-only, unprivileged, and with no network until you grant a host by name.

Choose per agent, by how much you trust its code: class: container | gvisor | microvm

step two · record

1transaction per step

Crash anywhere.
Resume exactly there.

Each step's result, the event that records it, and the next task commit together in Postgres. A node can die mid-run, and the run picks up from the last event, without calling a model twice.

step five · talk

Agents call each other
by name, not by address.

A service is a stable name that every instance of an agent serves. Requests time out cleanly, late replies never come back to haunt anyone, and topics fan out into durable mailboxes, so a subscriber that was down catches up.

step six · prove it

An audit log even your DBA
can't quietly edit.

Every privileged action and every denial goes into a hash-chained log, shipped off-site as it's written. Rewrite a row in the database and the copy says so.

3commands to a running cluster

Agents in sandboxes.
Every step on the record.

One control-plane binary on Postgres, and a small daemon on each machine that runs agents. No Kubernetes, no Temporal.

$ cargo build
$ ./target/debug/clankrd --dev
$ ./target/debug/clankr-node --server https://127.0.0.1:7600 \
    --join-token "$(cat ~/.config/clankr/join-token)" \
    --ca-cert ~/.local/share/clankr/pki/ca.crt --runtimes process

Then clank apply -f hello.yaml and watch it in the console at https://127.0.0.1:7600. Add kennel for sandboxed runtimes; the README has the full walkthrough.
